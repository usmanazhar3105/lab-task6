# Week 6 Informed Search - Tasks 1 to 5

Included:
- `week6_Tasks_completed_Tasks1-5.ipynb`: completed Tasks 1–5 with executed outputs preserved.
- `searchAlgos.py`: Task 3 hospital graph and reusable GBFS/A* implementations.
- `streamlit_app_completed.py`: completed Streamlit GUI based on the same Task 3 graph and algorithms.
- `requirements.txt`: required packages.

Run the GUI:
```bash
pip install -r requirements.txt
streamlit run streamlit_app_completed.py
```

Note:
The provided Streamlit template was used as the base and its missing sections were completed in `streamlit_app_completed.py`.
